# Your notes folder

Drop your own files here:

- typed notes or a transcript from a meeting, then type `/log` followed by the file name;
- the Word document and the Google Sheet export (.csv) for `/import`.

Claude reads files in this folder and never changes, moves or deletes them. Name files with the date first so they sort in order, for example `2026-11-05-jordan-one-to-one.docx`. Files can be `.txt`, `.md`, `.docx`, `.vtt` (Teams transcripts) or `.csv`.

Everything in here is about your staff. It stays on your laptop, is never uploaded, and is never touched when you update the template.
